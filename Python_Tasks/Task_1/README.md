# Python Task: Predict and Execute

## Objective
The objective of this task is to improve Python programming skills by predicting the output of code before execution and understanding why Python produces that output.

## Concepts Covered
- Empty Set and Dictionary
- Tuple Creation
- Truthiness and bool()
- True, 1, and 1.0 as Dictionary Keys
- Equality (==) vs Identity (is)
- List Concatenation (+) vs Augmented Assignment (+=)
- List Slicing
- del Statement: Names vs Objects
- Shallow Copy and Deep Copy
- *args and **kwargs
- print() vs return

## Task Details
- Total Questions: 50
- Programming Language: Python
- Platform: Jupyter Notebook
- File Format: .ipynb

## Problem-Solving Approach
Follow these steps for every question:

1. Predict the output before execution.
2. Understand the Python concept involved.
3. Execute the original code without modifying it.
4. Compare the predicted output with the actual output.
5. Explain why the output occurs using Python comments.
6. If an error occurs, record the error and explain its cause.
